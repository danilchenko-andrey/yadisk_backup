# yadisk_backup — hardened photoslice CLI

Эта ветка предназначена для консольной выгрузки photoslice на Linux/GCP.

**Начните с [README_SAFE.md](README_SAFE.md)**: ограничения, защита cookies,
сбор списка, пробная загрузка трёх файлов и проверка результата.

Два скрипта `unlim_download.py` и `unlim_worker.py` работают только на стандартной
библиотеке Python 3.10+. `pip install` не требуется. Веб-интерфейс и его установщики
удалены. Новая версия не использует `.env` и не доверяет старой базе загрузок.

Изменения проверены автономными тестами; живой аккаунт Яндекса ещё не использовался.
Исходный проект: [PXSYS13/yadisk_backup](https://github.com/PXSYS13/yadisk_backup),
базовый commit `b8c656bc5667c8fbbbc3cdd84fd85451d468d8ae`. Лицензия MIT сохранена.

Остальные скрипты обычного Диска сохранены от upstream, но не входят в проверенный
консольный сценарий и не нужны для него. `requirements.txt` предназначен для них.
